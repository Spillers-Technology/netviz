FOSS LAN scanner

NetViz

A modern desktop scanner for seeing what is on your local network, built around a native Go scan engine and live event stream.

View on GitHub Quick start

Focused by design

NetViz discovers hosts on an authorized CIDR, TCP-connect scans a small default port set, resolves names when possible, and streams results into table, graph, history, and export consumers.

  • Not an Nmap wrapper
  • No raw packet or SYN scanning
  • No vuln scanning or remote command execution

Try it locally

The first useful path is the Mac desktop app, with CLI parity for event output, saved scan history, and latest-run diffs. 

go test ./...
make build-cli
./bin/netviz-cli scan -cidr 192.168.1.0/24 -save
cd desktop && wails dev
